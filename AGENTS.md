# AGENTS.md

This repo is a **signed APT repository** deployed to GitHub Pages — not an application codebase. It hosts `.deb` packages built from two upstream repos and publishes them via `reprepro` + GH Pages. Treat the source of truth as executable config, not prose.

## Architecture

- `conf/distributions` — the single source of truth for the suite. Declares `Codename: stable`, `Architectures: amd64 arm64`, `Components: main`, and `SignWith` (the GPG key fingerprint).
- `db/`, `dists/`, `pool/` — generated by `reprepro`. **Committed state**: `publish.yml` commits them after every import so the next run merges into the previous set instead of rebuilding a snapshot from scratch (which would drop every package not imported by the latest dispatch). Never re-ignore them. Old versions accumulate in the pool; prune with `reprepro --basedir . deleteunreferenced` when needed.
- `public-key.asc` — committed public signing key. `private-key.asc` and `fingerprint` are **gitignored secrets**; never stage/commit them (see `SECURITY.md` for rotation).
- `.github/workflows/publish.yml` — the core pipeline. Imports every `*.deb` asset from the two source repo releases via `gh release download --pattern "*.deb"`, then `reprepro includedeb stable`, signs, and deploys to Pages. It is already arch-agnostic (imports all archs) — adding a new arch only requires updating `Architectures:` in `conf/distributions`.
- `.github/workflows/reconcile.yml` — scheduled hourly backstop that re-triggers `publish.yml` when a newer source release exists than what's published. Its `published_versions()` reads the Pages `binary-<arch>/Packages` indexes for `amd64 arm64`.
- Two upstream repos feed this one: `timlaing/dovecot-xaps-plugin` (binary `dovecot-xaps-plugin`) and `timlaing/dovecot-xaps-daemon` (binary `xapsd`). Their `release.yml` calls `repository_dispatch` (event `apt-release`) back to this repo.

## Verification

Local checks are driven by **`prek`** (a wrapper that runs the pre-commit hooks from `.pre-commit-config.yaml`; pre-commit is not on PATH directly — use `prek`):

```sh
prek                      # pre-commit hooks (trailing-whitespace, check-yaml, ruff, prettier, ...)
prek install -f           # bootstrap hooks in a fresh clone
```

APT integrity checks (requires `reprepro` + `lintian`):

```sh
reprepro --basedir . check
reprepro --basedir . export
lintian --fail-on error <file.deb>   # what the publish workflow gates on
```

The `Check` workflow (`.github/workflows/checks.yml`) runs `python3 -m scripts.check.edits` on PRs to enforce maintainer-editable PRs; the `SonarQube` workflow runs off a `workflow_run` after `Check`.

## Conventions

- `main` is the only long-lived branch; PRs base on `main`. Conventional commit prefixes (`feat:`/`fix:`/`docs:`/`chore:`) feed the Release Drafter — use them in PR titles and commits.
- **PRs must be editable by maintainers** (`scripts/check/edits.py` fails the build otherwise).
- Never target upstream forks — push/PR only to `timlaing/*`.
- Source repos only publish `amd64` today; `arm64` is declaration-ready but won't produce `binary-arm64/Packages` until the source CI builds arm64 debs.

## Environment

- Dev container uses Python (`.venv` via `uv`), Node (prettier plugins in `package.json`), and Docker. `scripts/setup.sh` (with `XPS_APT_INSTALL_DEV_TOOLS=1`) bootstraps tooling including the OpenCode CLI and SonarQube MCP server.
- SonarQube project key: `timlaing_dovecot-xaps-apt` (org `timlaing`). Local analysis: `sonarqube_analyze_file_list`; verify files before pushing.
- OpenCode session guidance (push approval, commit conventions) lives in `.opencode/private-instructions.md`, loaded via `opencode.json` — honor it.
